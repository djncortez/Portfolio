STMicroelectronics — B2F2 Operations 2/3
May 2026 — Present
480 hrs practicum engagement
Full Narrative Report →

Completed an on-the-job training practicum at STMicroelectronics, a global semiconductor manufacturer, where I was assigned to the B2F2 Operations 2/3 department. My core assignment was designing and building the MBO Sawing Report System — an internal web application that digitizes the department's MBO sawing report process, replacing a manual, Excel-based workflow with a structured, validated, and centrally managed reporting platform. I worked across the full stack: frontend, backend, database, testing, documentation, and the deployment presentation to the department.

Key Contributions
  • Controlled access & login — built an authenticated login flow restricting the workspace to authorized MBO personnel.
  • Workflow selection engine — let users choose the correct report variant (External / Lite / Internal PC MBO) before entering the reporting flow.
  • Guided landing dashboard — structured entry point for starting new reports, resuming drafts, and opening saved files.
  • Digitized summary & worksheet pages — translated the Excel worksheet logic into guided, section-based application pages.
  • Admin-managed configuration — centralized module for managing MBO type values instead of hardcoded spreadsheet fields.
  • Validation & guided correction — built-in checks that flag missing fields and reduce encoding errors.
  • Historical tracking & retrieval — saving and reloading of past reports from a centralized backend.
